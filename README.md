# Da Planta à Obra — Concreto Armado

Landing page estática em português, responsiva, criada com HTML e CSS. Não exige instalação de dependências nem etapa de build.

## Visualizar

Abra `index.html` no navegador ou rode `python3 -m http.server 8080` na pasta do projeto e acesse `http://localhost:8080`.

## Publicar

Envie `index.html`, `styles.css` e a pasta `assets` para uma hospedagem estática. A página usa caminhos relativos e funciona também em subdiretórios.

## Imagens e acessibilidade

As 12 imagens fornecidas foram convertidas para WebP, mantendo sua proporção e sem cortes. Cada imagem aparece uma única vez. A imagem principal tem prioridade; as demais usam carregamento preguiçoso. As perguntas frequentes usam os elementos nativos `details` e `summary`, compatíveis com teclado e sem JavaScript. O layout inclui link para pular ao conteúdo, foco visível e preferência por movimento reduzido.

As imagens são mockups promocionais. O repositório contém a página de vendas, não os arquivos entregáveis do produto. O pagamento e a entrega são tratados pelo checkout informado.
